# WS1 source-tarball ceiling survey (keyless)

Generated by `python -m evaluation.source_survey` — arXiv e-print fetch only,
no Anthropic API. Scanner: `pipeline/source_data.py`. GT = O'Hare repo files
via `evaluation/ground_truth` (exclusions skipped).

> **This is an ORACLE ceiling.** The survey picks the best candidate file,
> column pair, and unit transform by comparing against GT — the runtime
> channel must make those choices from pgfplots axis options, captions and
> heuristics instead. It bounds the prize from above; it does not claim the
> channel achieves it.

## Reading the result

- The channel is a **tail rescue, not a vision replacement**: only 3% of the pool has numeric source data (most papers ship figures as pre-rendered PDF/PNG graphics — the WS2 population), but where data exists it is near-exact, and the best candidates are overwhelmingly arXiv **ancillary files (`anc/`)** — curves the authors deliberately published.
- Several best candidates match GT to ~0.00 dex because the O'Hare repo file was built from the same published data. That is the point of the channel, not a scoring artifact: the source file IS the paper's own curve.
- WS2 note: the pre-rendered figures are mostly **vector** PDFs; a vector-path extraction pass (pymupdf `get_drawings()`) could recover exact coordinates for that population without raster CV.
